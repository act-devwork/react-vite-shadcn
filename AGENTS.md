# Project instructions

These instructions apply to the entire repository.

## Required project rules

- Before changing any file, read `.agents/rules/core-conventions.md`.
- For TypeScript, React, hooks, state, filters, or data-fetching work, also read
  `.agents/rules/react-data-architecture.md`.
- For API, authentication, authorization, environment, logging, or customer-data work, also read
  `.agents/rules/api-security.md`.
- Before changing dependencies and before handing off any implementation, read
  `.agents/rules/workflow-quality.md`.

## Task-specific skills

- For visual, layout, responsive, accessibility, interaction, form, table, dialog, loading, or
  empty-state work, read `.agents/skills/design-experience/SKILL.md`.
- For a feature, API integration, route, permission, filter, mutation, server/shared state, or
  socket behavior, read `.agents/skills/build-feature/SKILL.md`.
- Read both skills when a feature changes user-facing behavior.

## Instruction priority

- Follow the user's current request first, then this file, the applicable rule files, and the
  applicable skills.
- When instructions conflict, follow the more specific instruction and mention the conflict during
  handoff.
